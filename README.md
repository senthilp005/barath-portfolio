# P. Senthil Velan — Creative Developer Portfolio

Responsive React + Vite portfolio featuring an animated hero, filterable projects, skills, interactive simulated terminal, and contact links.

## Run locally
Requirements: Node.js and npm.
```bash
npm install
npm run dev
```
Open the localhost URL printed by Vite (usually http://localhost:5173).

## Customize before sharing
- Replace `your.email@example.com` in `src/main.jsx` with your real email.
- Update LinkedIn URL to your profile.
- Project cards currently link to the GitHub profile as a safe default. Replace each URL with the matching repository when ready.
- Add your resume file and a download link if desired.

## Build
```bash
npm run build
npm run preview
```

## Free hosting on Vercel
1. Open https://vercel.com/ and sign in with GitHub.
2. Import `senthilp005/barath-portfolio`.
3. Build command: `npm run build`; output directory: `dist`.
4. Deploy. Vercel will provide a public URL.

Contact links use mailto; this starter has no backend contact form. The terminal is a simulated portfolio interaction, not a real shell.
